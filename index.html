Двойных бронирований не бывает. Совсем.

REST API для бронирования переговорных и рабочих мест с ролями Guest, Member, Corporate Admin и System Admin. Конфликты исключены на уровне базы данных.

Роль Backend разработчикКод coworks_project ↗
V5__create_bookings_table.sql
CREATE EXTENSION IF NOT EXISTS btree_gist;

CREATE TABLE bookings (
    book_id     SERIAL PRIMARY KEY,
    room_id     INT REFERENCES rooms_desks(room_id),
    user_id     INT REFERENCES users(user_id),
    date        DATE NOT NULL,
    start_time  TIME NOT NULL,
    end_time    TIME NOT NULL,
    book_status VARCHAR(20) NOT NULL DEFAULT 'PENDING',
    EXCLUDE USING gist (
        room_id WITH =,
        tsrange(date + start_time, date + end_time) WITH &&
    ) WHERE (book_status <> 'CANCELLED'),
    CHECK (start_time < end_time)
);
🧱

EXCLUDE USING gist

Пересечения бронирований невозможны на уровне PostgreSQL — race condition исключён даже при конкурентных запросах.
